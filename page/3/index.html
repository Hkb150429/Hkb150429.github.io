【信息】知识点-差分约束系统

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 127 阅读时长 ≈ 1 分钟

核心思想：把不等式 x_j - x_i ≤ w 转化为有向边 i → j，权值 w，跑最短路

不等式形式 建边 求什么
x_j - x_i ≤ w i→j, w 最短路 → 最大值
x_j - x_i ≥ w i→j, -w（或 j→i, w） 最长路 → 最小值
x_j = x_i i→j,0 且 j→i,0 —
  • 超级源点：建点 0，向所有点连边权 0，保证连通
  • 无解：存在负环（求最短路时）/ 正环（求最长路时）
  • 常见模型：区间和约束、排队问题、时间调度

【信息】知识点-强联通分量

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 139 阅读时长 ≈ 1 分钟

Tarjan 算法

  • 核心数组：dfn[u]（时间戳）、low[u]（能到达的最小 dfn）
  • 过程：DFS 入栈，遍历邻边；回边更新 low；子节点返回后更新 low；若 low[u] == dfn[u]，弹栈到 u 即为一个 SCC
  • 复杂度：O(n+m)

Kosaraju 算法

  • 两遍 DFS：原图按后序逆序 → 反图 DFS 染色
  • 优点：实现简单，不易写错

缩点

  • 每个 SCC 缩成一个点，得到 DAG
  • 应用：DAG 上 DP（如最长路）、求最少加边使图强连通（max(入度为0点数, 出度为0点数)）、2-SAT

【信息】知识点-SPFA优化

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 90 阅读时长 ≈ 1 分钟
  1. SLF（Small Label First）：双端队列，新距离小于队首则插队首，否则队尾
  2. LLL（Large Label Last）：队首距离大于队列平均值则移到队尾
  3. 判负环替代：用 DFS 式 SPFA 判负环更快，但容易栈溢出
  4. 慎用场景：稠密图 SPFA 会被卡，优先 Dijkstra；网格图、菊花图易卡 SPFA

【信息】知识点-最短路

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 161 阅读时长 ≈ 1 分钟

Dijkstra（堆优化）

  • 适用：非负权图，单源最短路
  • 复杂度：O((n+m)log n)
  • 核心：优先队列存 (dist, u)，每次取最小未确定点松弛
  • 易错：用 vis 标记已出队节点，出队时若 d > dist[u] 直接跳过

Bellman-Ford / SPFA

  • 适用：负权图、判负环
  • SPFA：队列优化，平均 O(km)，最坏 O(nm)
  • 判负环：记录入队次数，cnt[u] > n 则存在负环；或用 cnt[u] 表示最短路边数，> n-1 即负环

Floyd

  • 适用：多源最短路、传递闭包，n ≤ 400
  • 复杂度：O(n³)
  • 核心：d[i][j] = min(d[i][j], d[i][k] + d[k][j])，k 在外层

【信息】知识点-割点和桥

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 167 阅读时长 ≈ 1 分钟

割点

  • 无向图中，删去该点后连通分量数增加
  • 判定：
    • 根节点：子树数量 ≥ 2
    • 非根节点 u：存在子节点 v 满足 low[v] ≥ dfn[u]
  • 注意：不能用 fa 简单跳过父边，要用边编号避免重边

桥（割边）

  • 删去后边数连通分量增加
  • 判定：边 (u,v) 为桥 ⟺ low[v] > dfn[u]
  • 重边处理：必须用边的编号判重，不能只看父节点

应用

  • 边双连通分量（E-BCC）：删去所有桥后每个连通块
  • 点双连通分量（V-BCC）：用栈存边，割点处弹栈
  • 圆方树：点双缩点建图，处理路径必经点问题

【信息】知识点-倍增求LCA

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 146 阅读时长 ≈ 1 分钟

预处理

  • fa[u][k]：u 的 2^k 级祖先
  • dep[u]：深度
  • DFS 求出 fa[u][0] 和 dep[u]，然后递推 fa[u][k] = fa[fa[u][k-1]][k-1]
  • 复杂度：预处理 O(n log n)，查询 O(log n)

查询步骤

  1. 把深度大的点往上跳到同一深度
  2. 若两点相同直接返回
  3. 从高位到低位枚举 k，若 fa[u][k] != fa[v][k] 则同时上跳
  4. 返回 fa[u][0]

扩展

  • 倍增可同时维护路径上的最大值/最小值/和
  • 树上第 k 大祖先、树上差分配合 LCA

【信息】知识点-树状数组

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 229 阅读时长 ≈ 1 分钟

原理

  • 利用 lowbit(x) = x & -x
  • 数组大小 n，下标从 1 开始
  • 单点修改 + 前缀查询：O(log n)

基础操作

扩展用法

  1. 区间修改 + 单点查询：差分思想，修改 [l,r] 即 add(l,v), add(r+1,-v)
  2. 区间修改 + 区间查询：维护两个树状数组 t1 和 t2，前缀和 = (x+1)*query(t1,x) - query(t2,x)
  3. 求逆序对：离散化后从后往前插入，查询比当前小的数量
  4. 第 k 小：倍增式查询，从高位试探
  5. 二维树状数组：套一层循环，处理矩形和

与线段树对比

  • 树状数组常数小、代码短，但只能做满足可逆、可差分的操作（和、异或）
  • 最值、最大子段和等不可差分操作必须用线段树

【信息】知识点-树链剖分

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 164 阅读时长 ≈ 1 分钟

核心概念

  • 重儿子：子树最大的儿子
  • 重链：连续重儿子组成的链
  • 轻边：非重边，每次走轻边子树大小至少减半 → 任意路径轻边数 ≤ log n

两次 DFS

  1. DFS1：求 siz[u]、dep[u]、fa[u]、son[u]（重儿子）
  2. DFS2：求 top[u]（链顶）、dfn[u]（线段树下标），优先遍历重儿子保证重链 dfn 连续

核心操作

  • 路径修改/查询：while 两点 top 不同，深度大的跳到 fa[top[u]]，期间用线段树操作 dfn 区间
  • 子树修改/查询：子树 dfn 连续，区间 [dfn[u], dfn[u]+siz[u]-1]
  • 复杂度：O(log² n) 每次操作

【信息】知识点-线段树

发表于 2026-08-12 分类于 information-technology 阅读次数： 本文字数： 182 阅读时长 ≈ 1 分钟

基本结构

  • 数组开 4 倍空间
  • 支持区间修改、区间查询，单点修改更简单
  • 懒标记（lazy tag）：区间修改时不下传，查询/修改子区间时再 pushdown

常见变体

类型 维护信息
区间加 + 区间和 sum, lazy
区间乘 + 区间加 sum, mul, add（先乘后加）
区间最值 mx/mn, lazy
区间赋值 val, lazy（用特殊值标记无标记）
最大子段和 sum, mx, pre, suf
吉司机线段树 区间取 min/max，维护最大值、次大值、计数

易错点

  • pushdown 后必须清空父节点标记
  • 区间修改时标记叠加顺序（先乘后加：add = add*mul + new_add）
  • 边界：l > r 直接返回，完全覆盖再操作
