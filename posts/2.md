## 题意

有一个长方形，求同面积整数边长这样长方形个数。

## 思路

暴力枚举 $1$ 至 $\sqrt n$ 边长，大于 $\sqrt n$ 就会重复。

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n,s=0;
    cin>>n;
    for(int i=1;i<=sqrt(n);i++){
        if(n%i==0)s++;
    }
    cout<<s;
}
```

结果 `	100ms  /   1.04MB  /   160B C++14 (GCC 9) O2`
