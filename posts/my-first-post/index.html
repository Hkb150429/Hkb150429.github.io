🧪 博客组件全面测试

Contents

这篇文章用来测试博客所有已安装的组件是否正常工作。

💡 如果下面所有内容都正常显示，说明你的博客配置完美！如果某个部分没显示，那就是对应的组件需要检查。

📋 测试清单

  • 暗色/亮色模式切换
  • 多语言自动翻译
  • 小鱼游动动画
  • 网易云音乐播放器
  • B站视频嵌入
  • 思维导图
  • 代码高亮
  • 提示框 (Admonition)
  • 标签页 (Tabs)
  • GitHub 项目展示
  • 图片处理
  • JSON 订阅

1. 🌓 暗色/亮色模式

点击右上角的 月亮/太阳图标，页面颜色应该会切换。

  • 🌞 亮色模式：白色背景
  • 🌙 暗色模式：深色背景

2. 🌐 多语言自动翻译 (cmpt-translate)

点击右上角的 地球图标，选择不同语言：

  • English
  • 简体中文
  • 日本語
  • 한국어

文章内容应该会自动翻译。

3. 🐟 小鱼游动动画 (cmpt-flyfish)

仔细看页面背景，应该有浅蓝色（亮色模式） 或浅白色（暗色模式） 的小鱼在游动。

如果看不到，可能是颜色太淡了。可以在 hugo.toml 中调整透明度。
