例题：P3478 STA‑Statistics，求每个点到所有点距离和

1.什么是换根DP

普通树形DP：只算以1为根的答案。
换根DP：求树上每一个点当作根的答案。

暴力：每个点跑一遍dfs，O(n²)，n=1e5直接超时。

换根DP思路：

  1. dfs1：任选一个根（一般取1），算出子树信息。
  2. dfs2：把根从父节点u挪到子节点v，利用u的全局答案直接算出v的全局答案，不用重遍历。
    总复杂度 O(n)。

核心：找到「根从u换到v」时答案的变化量。

2.例题：求每个点到全部点的距离总和

定义：

  • sz[u]：以u为根的子树节点数量
  • dp[u]：以u为根时，u子树内部所有点到u的距离总和（只看子树）
  • f[u]：整棵树以u为根，全树所有点到u的距离总和（题目要求输出的答案）

dfs1(1,-1) 后序求子树信息

对于子节点v：

  1. sz[u] += sz[v]
  2. u到v子树所有点的距离 = v到那些点距离 + 1；一共sz[v]个点，所以 dp[u] += dp[v] + sz[v]

跑完dfs1，f[1] = dp[1]，1号点作为全局根的答案。

dfs2：换根推导（最重要）

把根从u移动到儿子v，只改变u‑v这条边：

  1. v的子树一共有 sz[v] 个点：这些点距离根全部减1，总距离减少 sz[v]。
  2. 剩下外面 n‑sz[v] 个点：这些点距离根全部加1，总距离增加 (n‑sz[v])。

转移等式（单行，无换行）：
f[v] = f[u] - sz[v] + (n - sz[v])

注意：先算出f[v]，再递归v的子节点。顺序不能颠倒。

3.换根DP通用做题步骤

  1. 选定初始根，一般选1。
  2. dfs1(u,fa)：后序遍历，求子树信息 sz、dp。只处理u的子树，不处理u上方部分。
  3. 给初始根赋值：f[root]=dp[root]。
  4. dfs2(u,fa)：从上到下，父推子，算出f[v]。

⚠️顺序：先算f[v]，再递归dfs2(v)。

  1. 输出f数组。

dfs1：子 → 父（后序）
dfs2：父 → 子（先序）

4.怎么推导换根公式（思考模板）

  1. u是父，v是儿子，画图；
  2. 根从u移到v，只有u‑v这条边反转；
  3. 树切两块：
    • A块：v的子树，点数 sz[v]
    • B块：其余所有点，点数 n‑sz[v]
  4. 判断A块、B块总答案分别加多少、减多少，合并得到f[v]。

提醒：f[v]=f[u]-sz[v]+(n‑sz[v])只是距离和专用，别的题目要重新推。

5.易错点

  1. 漏写fa判断，dfs死循环爆栈。
  2. dfs2递归顺序错：先递归子节点再算f[v]，结果全错。
  3. 答案很大，必须用long long，int会溢出。
  4. 分清两个数组：
    • dp[u]：仅u子树内部答案，dfs1求出
    • f[u]：整棵树以u为根的全局答案，dfs2求出
  5. 忘记写 f[1]=dp[1]。

6.什么时候想到换根DP

题目要求：树上每一个点作为根，求某个代价/权值/距离，输出全部点的结果。

只求一个点答案，普通树形DP就够，不用换根。
